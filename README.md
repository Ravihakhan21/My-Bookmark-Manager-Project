# 🔖 Bookmark Manager

A simple and clean Bookmark Manager web project built using HTML and CSS — created by **Raviha Khan** as part of my learning journey in web development. This is my first website project, and I'm excited to keep improving as I learn more! 💻✨
---

## 📚 About the Project

This project is designed to organize and manage useful website links into two categories:

- ✅ **Primary Bookmarks**: Frequently used websites like Google, YouTube, Facebook, etc.
- 🧩 **Secondary Bookmarks**: Informative platforms like Wikipedia and StackOverflow

All links open in a new tab for smooth user experience.
